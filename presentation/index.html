03 // PROBLEM CONTEXT & MOTIVATION
Cognitive Friction in Modern Digital Workspaces
Bridging the sensory disconnect between static web interfaces and human mental capacity
// 01 THE PROBLEM: UNNOTICED COGNITIVE OVERLOAD
• Mental exhaustion accumulates silently, increasing task error rates by up to 40%.
• The human brain lacks an explicit sensory gauge to detect mental fatigue before failure.
// 02 EXISTING LIMITATIONS: INVASIVE OR OBLIVIOUS TOOLS
• Traditional Web UIs are static—treating exhausted users identically to fresh users.
• Prior physiological systems mandate clinical EEG caps or chest straps unusable for desk work.
// 03 OUR SOLUTION: CLOSED-LOOP BIOCYBERNETICS
• Fuses consumer smartwatch PPG signals with natural browser interaction telemetry.
• Calculates individualized resting baseline deltas (ΔHR, RMSSD) to drive subtle UI adaptations.

05 // CRITICAL ANALYSIS
Challenges & Formulated Research Gap
Overcoming four core bottlenecks that prevent laboratory physiological computing from reaching consumer web systems
// 01 HARDWARE INVASIVENESS
Barrier: Clinical EEG caps or chest straps are unusable for regular desktop computing.
Solution: Strict consumer boundary (standard browser + BLE smartwatch PPG).
// 02 INTER-SUBJECT VARIABILITY
Barrier: Resting HR varies from 50 to 90 bpm; static thresholds trigger false alarms.
Solution: Continuous baseline calibration computing resting deltas (ΔHR = HR - HR_rest).
// 03 SENSOR NOISE & DROPOUTS
Barrier: Wrist motion causes packet drops; zero-filling missing streams corrupts models.
Solution: Explicit availability_mask routing with tri-branch fallback (Wearable, Task, Fused).
// 04 UI OSCILLATION & BLACK-BOX AI
Barrier: Black-box AI causes biocybernetic thrashing without evidence attribution.
Solution: 7-step Follow-the-Signal audit trace + bounded hysteresis with cooldowns.
THE CORE FORMULATED RESEARCH GAP
"The absence of an explainable, noise-tolerant biocybernetic framework that reliably estimates multidimensional cognitive states from consumer-grade wearables and desktop telemetry without requiring clinical invasiveness, zero-filled signal corruption, or disruptive interface oscillation."

06 // SCOPE & DELIVERABLES
Project Objectives & Engineering Scope
Five precise, measurable, and implementation-oriented engineering milestones
OBJ 01
ENGINEER DUAL-STREAM INGESTION & SYNCHRONIZATION PIPELINE
Ingest consumer BLE smartwatch PPG (Bluetooth GATT Service 0x180D) and browser task interaction telemetry, synchronizing data into non-leaking 30-second sliding windows with timestamp verification and gap handling.
OBJ 02
IMPLEMENT INDIVIDUALIZED BASELINE CALIBRATION & DELTA EXTRACTION
Compute normalized physiological deltas (ΔHR = HR_curr - HR_rest) against personalized resting baselines to neutralize inter-subject variance, supported by an explicit missing-modality mask (availability_mask).
OBJ 03
DEVELOP TRI-STATE MULTIMODAL INFERENCE & CONFIDENCE GATING
Implement baseline classification models estimating three independent cognitive constructs—Workload, Fatigue, and Engagement—accompanied by quality gating (PASS, DEGRADED, INSUFFICIENT) rather than ungrounded black-box predictions.
OBJ 04
ARCHITECT 7-STAGE "FOLLOW-THE-SIGNAL" EXPLANATION PIPELINE
Establish a transparent, non-causal evidence attribution audit trail allowing users to trace any UI intervention backwards through 7 verification stages to the exact raw sensor events that triggered it.
OBJ 05
DEPLOY CLOSED-LOOP ADAPTIVE WEB EXPERIENCE WITH HYSTERESIS
Deliver bounded, non-disruptive web UI interventions (micro-break prompts, task difficulty modulation, notification throttling) governed by hysteresis thresholds and cooldown timers to eliminate interface thrashing.
